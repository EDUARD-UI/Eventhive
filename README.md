# Event Hive — Frontend

## Stack
React + Vite + Tailwind CSS + React Router + SweetAlert2 + React Icons + LUCIDE icons + n8n + Google Gemini IA.

## Instalación

```bash
npm install
npm run dev
```

## 🤖 Asistente Virtual Inteligente (HiveBot con n8n)
El proyecto incluye un asistente con IA integrado a través de n8n y Google Gemini. Para configurarlo y ponerlo en marcha en tu máquina local, consulta la guía paso a paso:
